# Brand Media Bible - XE KHO CHUA LANH

Source pack: `02_brand_media_bible_XE_KHO_CHUA_LANH.md`.

Operational rules for automation:

- Voice: warm, close, healing, casual, appetizing, lightly playful.
- Avoid: hard-sell captions, invented dishes/prices/ingredients, too many emoji, fake-looking food, neon/sale-heavy design.
- Visual mood: warm light, wood, charcoal, cream, night chill, street food with taste.
- Preferred formats: `4:5` feed, `1:1` square, `9:16` story/reel.
- Publish gate: do not use raw assets. Use only `REFINED`, `TAGGED`, `PUBLISH_READY`, or `HERO_ASSET`.
- If publish-ready media is missing, request refine/manual edit/new shoot instead of generating weak content.
